# ArrowLang

ArrowLang is an implementation of an arrow calculus with operations and handlers.

## Build and install

Install [Rust](https://www.rust-lang.org/tools/install) and

```bash
cargo install --path .
```

Then a command `arr` will be installed.

To uninstall,

```bash
cargo uninstall arr
```

## Run interpreter

```bash
$ arr ./example/example1.arr
2001
300
```
